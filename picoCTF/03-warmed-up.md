# Warmed Up

**Category:** General Skills | **Difficulty:** Easy | **Source:** picoCTF 2019

## Challenge
What is 0x3D (base 16) in decimal (base 10)?

## Approach
Converted hex 3D to decimal manually: 
(3 × 16) + (D, which equals 13 in hex) = 48 + 13 = 61.
Verified using CyberChef's "From Base" operation (base 16 to base 10).
