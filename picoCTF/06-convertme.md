# convertme.py - picoCTF

## Category: General Skills
## Difficulty: Easy
## Tags: base, Python

## Description
Python script converts a given decimal number to binary to reveal the flag.

## Approach

1. Downloaded the Python script using wget in the webshell:
   $ wget <script_url>

2. Ran the script:
   $ python3 convertme.py

3. Script gave a decimal number as output/prompt.

4. Converted the decimal number to binary 
   (using online converter or manual calculation)

5. Entered/used the binary value to get the flag.

## Learning
- Basic number system conversions (decimal to binary) are 
  common in beginner CTF challenges
- Simple Python scripts can be run directly via python3 
  in a webshell environment
- Always read script output carefully - it often gives 
  clues on what conversion or transformation is needed
