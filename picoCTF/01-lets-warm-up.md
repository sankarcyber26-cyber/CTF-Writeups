# Lets Warm Up

**Category:** General Skills | **Difficulty:** Easy | **Source:** picoCTF 2019

## Challenge
If a word started with 0x70 in hexadecimal, what would it start with in ASCII?

## Approach
Used an ASCII table to look up hex value 70. Found that 0x70 corresponds 
to the letter 'p' in ASCII.
